# Imagens da documentação

Todos os caminhos usados pelo README são relativos ao repositório. Mantenha
`docs/images/` junto do README ao publicar no GitHub.

| Arquivo | Origem |
| --- | --- |
| `images/tamp-banner.png` | Capa de aparência fotográfica gerada por IA com a ferramenta integrada de geração de imagens. Não é foto de uma instalação real. |
| `images/cli-ajuda.png` | Saída real de `bash install.sh --help`, renderizada com tipografia de terminal. |
| `images/uso-servicos.png` | Demonstração gráfica com comandos e saídas ilustrativas baseadas na CLI. Não é screenshot de Android. |

As imagens não contêm senhas, bancos ou projetos pessoais. Não use demonstrações
como prova de execução de testes. Para substituir por screenshots reais, capture
uma sessão no Termux com dados de exemplo e oculte informações pessoais.

## Atualizar as imagens

Ao alterar opções da CLI, gere uma nova saída com `bash install.sh --help` e
atualize a imagem da ajuda. Mantenha os avisos de origem das imagens no README.
Não foi adicionada uma licença ao código: a decisão de licenciamento cabe ao autor.
